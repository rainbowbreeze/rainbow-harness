# Inbox (`inbox/`) — Temporary Staging

> **Purpose:** Staging area for quick captures, fleeting notes, or uncategorized observations before walking the resolver.

---

## 1. What Goes Here
- Raw dumps, voice-to-text captures, links needing reading.
- Slug convention: `capture-slug.md`

## 2. Invariant Rule
- The inbox is **temporary**.
- During routine maintenance (`bun run lint` / `skills/maintain/SKILL.md`), items in `inbox/` must be categorized into their permanent MECE directory and removed from here.
