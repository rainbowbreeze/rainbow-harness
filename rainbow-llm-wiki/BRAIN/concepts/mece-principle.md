# MECE Principle

> A structuring framework requiring categories to be mutually exclusive (no overlap) and collectively exhaustive (no gaps).

## Definition & Core Rules
- **Mutually Exclusive (ME):** Each fact, entity, or note lands in exactly one primary home. No duplicate pages or split-brain records.
- **Collectively Exhaustive (CE):** All possible domain entities are accommodated by the directory schema or routed to `inbox/`.

## Application in Knowledge Bases
- Prevents knowledge rot caused by multiple conflicting copies of the same fact.
- Real-world multi-faceted entities live in one primary home, with secondary relationships expressed via cross-links.
